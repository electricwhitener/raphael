# 6. Features

*Outline. Each feature section is written when its ROADMAP stage is done.*

- 6.1 Running any Java program: paste, open, examples, stdin
- 6.2 Moving through a run: play, speed, step, skip call, finish call, jump to a line
- 6.3 Reading the picture: blue for "about to happen", amber for "just changed", grey for the line that just ran, red for errors
- 6.4 Structures drawn: arrays, grids, lists, trees, B-trees, tries, collections, boxes (more in stage 10)
- 6.5 Exceptions in the student's program (stage 7)
- 6.6 Saving and reopening runs; files used by the student's program (stage 8)
- 6.7 Synchronised views: trace table, history, memory, sequence diagram, flowchart, input (stage 9)
- 6.8 Learning modes: predict, line counter, growth chart, side by side (stage 11)
- 6.9 Exports (stage 12)
- 6.10 The interface (stages 4 and 4b): system file dialogs (and Windows' own inside WSL), icon toolbar, one dialog style with platform button order, first-run guide, settings, menu bar, keyboard reach, drag and drop, fonts
