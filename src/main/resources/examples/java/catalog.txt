## Classes and objects
oop/ClassesAndObjects | Classes and objects | A class is a blueprint; each new makes another object with its own fields.

## OOP principles
### Encapsulation
oop/Encapsulation | Encapsulation | Private fields, changed only through methods that check the values.
oop/ImmutableClass | An immutable class | Final fields and no setters: a change makes a new object.
### Inheritance
oop/Inheritance | Inheritance | A subclass gets its parent's fields and methods, and calls super(…).
oop/ConstructorChaining | Constructor chaining | super(…) runs the parent's constructor first, all the way up.
### Polymorphism
oop/Polymorphism | Polymorphism | One call, area(), runs a different method for each kind of shape.
oop/Overloading | Overloading | Methods with one name and different parameters.
### Abstraction
oop/Abstraction | Abstract classes | An abstract method each subclass must write for itself.
oop/Interfaces | Interfaces | A class can promise several abilities by implementing interfaces.
oop/DefaultMethods | Default methods | An interface method with a body, used or overridden.
### Putting it together
oop/Lambdas | Lambdas | An anonymous class and a lambda, both handed to sort().
oop/Composition | Composition | An object built from other objects: a car has an engine.
oop/Generics | Generics | One Box class that holds any type, checked by the compiler.
oop/BankAccounts | All together: bank accounts | An interface, an abstract class, inheritance, polymorphism and an exception.
oop/Shapes | A program in several files | Four files: an interface, two shapes and Main. See the Explorer tab.

## Exceptions

oop/CustomException | Your own exception | A checked exception class of your own, thrown and caught.
oop/Exceptions | Exceptions in a stack | Throwing, catching, rethrowing with a cause, and finally.

# Algorithms
## Sorting
sorting/BubbleSort | Bubble sort | Swaps neighbours until the biggest values bubble to the end.
sorting/SelectionSort | Selection sort | Finds the smallest value left and swaps it to the front.
sorting/InsertionSort | Insertion sort | Slides each value left until it's in order.
sorting/ShellSort | Shell sort | Insertion sort on values far apart, with the gap shrinking to 1.
sorting/MergeSort | Merge sort | Sorts each half, then merges the two sorted halves.
sorting/QuickSort | Quick sort | Splits around a pivot, then sorts each side.
sorting/HeapSort | Heap sort | Builds a max-heap, then moves the biggest value to the end.
sorting/CountingSort | Counting sort | Counts each value, then writes them out in order.
sorting/RadixSort | Radix sort | Sorts by the last digit, then the tens, then the hundreds.
sorting/BucketSort | Bucket sort | Drops values into buckets by range, sorts each, joins them.
sorting/SortingObjects | Sorting objects | Comparable and a Comparator decide the order of objects.

## Searching
searching/LinearSearch | Linear search | Checks each value in turn.
searching/BinarySearch | Binary search | Halves a sorted array at every step.
searching/TwoPointers | Two pointers | Finds a pair with a given sum, from both ends of a sorted array.

## Recursion and backtracking
recursion/Factorial | Factorial | A method that calls itself, and the base case that stops it.
recursion/SumArray | Sum of an array | The first value plus the sum of the rest.
recursion/FastPower | Fast power | x^n from x^(n/2): about log n calls.
recursion/ReverseString | Reverse a string | Reverse the rest, then add the first letter.
recursion/RecursivePalindrome | Palindrome, recursively | Match the ends, then check the middle.
recursion/RecursiveBinarySearch | Binary search, recursively | Each call searches half the range.
recursion/Fibonacci | Fibonacci | Two recursive calls each time: watch the call stack grow.
recursion/TowersOfHanoi | Towers of Hanoi | Moving n disks means moving n−1 disks twice.
recursion/Subsets | Subsets | Leave each letter out, or put it in: a tree of calls.
recursion/FloodFill | Flood fill | Fill a cell, then its four neighbours.
recursion/Permutations | Permutations | Swap, recurse, swap back: every order of A, B and C.
recursion/NQueens | N queens | Backtracking: place a queen, and undo it when it leads nowhere.

## Dynamic programming
dp/FibDP | Fibonacci table | Each answer is built from the two before it.
dp/GridPaths | Grid paths | Ways to cross a grid, from the cells above and to the left.
dp/CoinChange | Coin change | The fewest coins for each amount up to the target.
dp/Knapsack | 0/1 knapsack | The best value for each item count and capacity.
dp/LongestCommonSubsequence | Longest common subsequence | A table comparing two strings letter by letter.
